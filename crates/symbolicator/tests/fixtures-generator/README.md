# Reproducible compiler fixtures

From the repository root:

```sh
crates/symbolicator/tests/fixtures-generator/generate.sh all
cargo test -p symbolicator
```

Only Docker and network access are required for generation. `javascript` and `jvm`
select individual families. Docker images are pinned by digest; npm dependencies
are exact versions with a committed lockfile and `npm ci`; JVM compiler versions
are pinned, and the downloaded R8 jar has a verified SHA-256. Host source mounts
are read-only, dependencies are installed under container `/tmp`, and generated
files are the only writable host mount. Containers are removed on exit. Cargo tests
use the checked-in fixtures.

The JavaScript image uses `linux/amd64` because the distributed Hermes compiler is
an x86 Linux binary; ARM hosts need Docker's x86 emulation (Docker Desktop/OrbStack
provide it). The fixture source is a tiny application with a nested throwing call.

| Producer | Version | Input / independent oracle |
| --- | --- | --- |
| Rollup | 4.63.4 | IIFE, source-root and indexed-section variants; Mozilla `source-map` positions |
| Rolldown | 1.2.9 | Minified JS, TypeScript classes, and indexed sections; Mozilla `source-map` positions |
| webpack | 5.111.1 | Production, development and `nosources-source-map` bundles; Mozilla `source-map` positions |
| Metro | 0.87.1 | Execute Android release JS bundle; `metro-symbolicate` positions/scopes |
| Hermes compiler | 250829098.0.19 | Compile Metro output to bytecode, compose maps, probe real bytecode positions using `metro-symbolicate` |
| ProGuard | 7.6.1 | Compile Java, optimize/obfuscate, execute actual crash, official `proguard.retrace.ReTrace` |
| R8 | 8.3.37 | Compile Java, optimize/obfuscate with classfile backend, execute actual crash, official R8 Retrace |

Expected outputs are never generated by the Rust implementation. For JS we format
independently resolved positions in our documented stacktrace style; the oracle
provides source, line, column, and name. Generated runtime frames without source
locations remain unchanged. R8/ProGuard outputs come directly from the retracer.
Hermes inputs are **compiler-derived position probes, not captured device crashes**.
The Hermes map includes Metro's function metadata, so tests verify scope names in
addition to offsets. R8 classfile fixtures are not an Android DEX runtime test.

Indexed-map cases wrap real compiler maps with a line and column offset; the
bundlers do not emit these section wrappers themselves. Source-root cases add a
root to a real map. Each browser fixture also has Firefox-style frames converted
from the Node trace, rather than captured in Firefox. Tests cover LF, CRLF, and a
missing final newline.

Both JVM compilers generate a basic crash and a custom exception with a cause,
suppressed exception, nested classes, overloaded methods, and recursive frames.
R8 8.3's default retrace pattern misses some custom exception headers, so the
exception case passes an explicit `--regex`. Expected output still comes directly
from R8; the script and `generator.txt` record this option.

Artifacts live in `../fixtures/generated`. Each family includes provenance,
its map, input trace and expected trace; JS families also retain the generated
bundle, and Hermes retains its compiler map. Stable container paths avoid host
path leakage. The curated fixtures cover edge cases the tiny programs do not
naturally produce (outlines, rewrite metadata, malformed data, CRLF, ambiguity).

To update a JS tool, change the exact package version, update `package-lock.json`
inside a Node container, run this script, and review map/trace diffs. For a JVM tool,
update `jvm/pom.xml` or the R8 URL/checksum in `jvm/generate.sh`. Do not rewrite
expected outputs to match a Rust failure: investigate the producer/oracle first.
